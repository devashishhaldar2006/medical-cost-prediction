# Medical Cost Prediction

A data-analysis project exploring the factors associated with medical insurance charges. The included notebook loads the insurance dataset, performs exploratory analysis, and builds a foundation for predictive modeling.

## Contents

- `Medical-cost.ipynb` - analysis, visualizations, and modeling workflow
- `insurance.csv` - source dataset

## Getting started

Open the notebook with Jupyter or another compatible notebook environment, then run the cells from top to bottom. Typical dependencies include pandas, NumPy, Matplotlib, Seaborn, and scikit-learn.

> This project is for educational data-science practice and is not medical or financial advice.
